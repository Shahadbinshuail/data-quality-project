# مشروع رفع جودة بيانات حجوزات الفنادق

---

## 1. الملخص التنفيذي
يهدف المشروع إلى رفع موثوقية بيانات حجوزات الفنادق من خلال تحديد عناصر البيانات ذات الأولوية، وقياس جودتها وفق أبعاد الجودة المختلفة (**الاكتمال، الانفراد، التوقيت، الصلاحية، الدقة، الاتساق**)، وتصميم قواعد جودة قابلة للقياس، ثم تسجيل المشكلات وتحليل أسبابها ومعالجتها والتحقق من نتائج المعالجة.

تُطبق المنهجية مبدئيًا على ملف تجريبي يتضمن **36 سجل حجز و17 عنصر بيانات**، وأظهر الفحص الأولي عددًا من المشكلات التي تتطلب مراجعة، مثل التكرار، النواقص، واختلاف القيم والتواريخ.

---

## 2. عناصر البيانات ذات الأولوية
تُحدد الأولوية بناءً على أهمية العنصر للعمليات، وأثر الخطأ، وانتشار الاستخدام، وقابلية القياس والإصلاح:

| الأولوية | العناصر | مبرر الاختيار |
| :--- | :--- | :--- |
| **عالية** | رقم الحجز، تاريخ الوصول والمغادرة، حالة الحجز، قيمة الحجز وحالة الدفع. | ترتبط بتعريف الحجز وتتبع الإقامة والتوافر والتقارير المالية. |
| **متوسطة** | اسم الفندق، المدينة، نوع الغرفة، رقم العميل وبيانات التواصل. | تؤثر على التخصيص والتواصل والربط بين السجلات. |
| **لاحقة** | قناة الحجز والحقول التحليلية المساندة. | تدعم التحليل والتقارير ويمكن توسيع ضبطها بعد تثبيت العناصر الأساسية. |

---

## 3. أبعاد جودة البيانات

| البعد | المقصود | التطبيق على بيانات الحجوزات |
| :--- | :--- | :--- |
| **الاكتمال** | توفر البيانات المطلوبة وعدم فقدان القيم الإلزامية. | وجود رقم الحجز والفندق وتواريخ الإقامة والحقول المطلوبة للتواصل. |
| **الانفراد** | عدم وجود تكرار غير مبرر. | عدم تكرار رقم الحجز، والتحقق من التكرار قبل الدمج أو الحذف. |
| **التوقيت** | حداثة البيانات وتوفرها في الوقت المناسب. | تحديث حالة الحجز والدفع عند حدوث التغيير وفي الوقت المطلوب تشغيليًا. |
| **الصلاحية** | التزام القيمة بالنوع والصيغة والنطاق والقيم المسموحة. | صحة صيغة البريد والتواريخ، وأن يكون عدد النزلاء عددًا صحيحًا موجبًا. |
| **الدقة** | مطابقة البيانات للواقع أو لمصدر مرجعي موثوق. | مطابقة قيمة الحجز وحالة الدفع مع المصدر المالي المعتمد. |
| **الاتساق** | عدم تعارض القيم داخل البيانات أو بين الأنظمة. | توافق الفندق مع المدينة، وتوحيد حالات الحجز والدفع بين الأنظمة. |

---

## 4. قواعد جودة البيانات المقترحة

| المعرف | العنصر / البعد | قاعدة الجودة وآلية التحقق | العتبة الأولية |
| :--- | :--- | :--- | :--- |
| **DQ-01** | رقم الحجز – الانفراد | عدم تكرار رقم الحجز دون مبرر موثق؛ يقاس عدد المعرفات المكررة إلى إجمالي المعرفات. | صفر تكرار غير مبرر. |
| **DQ-02** | رقم الحجز – الاكتمال | وجود رقم حجز لكل سجل ضمن النطاق. | 100% |
| **DQ-03** | رقم الجوال – الاكتمال | اكتمال رقم الجوال للسجلات التي تتطلب التواصل مع العميل. | يحدد حسب متطلب العمل. |
| **DQ-04** | التواريخ – الصلاحية | أن يكون تاريخا الوصول والمغادرة صالحين، وأن تكون المغادرة بعد الوصول. | 100% |
| **DQ-05** | عدد النزلاء – الصلاحية | أن تكون القيمة عددًا صحيحًا أكبر من صفر. | 100% |
| **DQ-06** | قيمة الحجز – الدقة | مطابقة القيمة للمصدر المالي المعتمد والتحقق من القيم غير المعتادة. | تحدد بعد اعتماد مصدر الحقيقة. |
| **DQ-07** | حالات الحجز والدفع – الاتساق | استخدام القيم المرجعية المعتمدة وعدم وجود قيم خارج القاموس. | 100% بعد اعتماد القاموس. |
| **DQ-08** | الفندق والمدينة والغرفة – الاتساق | توافق الفندق مع المدينة ونوع الغرفة وفق المرجع المعتمد. | 100% بعد ربط المرجع. |

## 5. نتائج التقييم المبدئي وفحص البيانات (Data Profiling)

| نتيجة الفحص الأولي للعينة | النتيجة | ملاحظة التفسير |
| :--- | :--- | :--- |
| **حجم البيانات** | 36 سجلًا / 17 حقلًا | العينة المتاحة للمشروع. |
| **اكتمال رقم الجوال** | 97.22% | يعني وجود قيمة واحدة غير مكتملة ضمن العينة. |
| **أرقام حجز مكررة** | 2 | سجلان ضمن مجموعة معرفات مكررة؛ يلزم التحقق قبل أي دمج. |
| **تواريخ تحتاج مراجعة** | 3 حالات | حالة تعذر تحويل تاريخ، وحالتان تكون فيهما المغادرة قبل أو تساوي الوصول. |
| **قيم حالات خارج القاموس** | حالة حجز: 1 / حالة دفع: 3 | تحتاج اعتماد القيم المرجعية من التشغيل والمالية. |
| **قنوات حجز خارج القاموس** | 6 | قد تكون اختلافات تسمية أو قنوات صحيحة لم تدرج في القاموس. |

## 6. سجل مشكلات جودة البيانات (Issue Register)

| مثال لمشكلة مرشحة | البعد / القاعدة | الإجراء الأولي المقترح |
| :--- | :--- | :--- |
| وجود أرقام حجز مكررة. | الانفراد / DQ-01 | مراجعة السجلات ومصدر إنشاء رقم الحجز وتحديد السجل الصحيح. |
| نقص رقم جوال في سجل. | الاكتمال / DQ-03 | التحقق مما إذا كان الجوال إلزاميًا لهذا النوع من الحجوزات. |
| تاريخ مغادرة يسبق أو يساوي الوصول. | الصلاحية / DQ-04 | التحقق من الإدخال ومصدر التاريخ وتصحيح القيمة بعد اعتمادها. |
| قيم حالات أو قنوات خارج القاموس الأولي. | الاتساق / DQ-07 | مراجعة القاموس مع مالك العملية قبل توحيد القيم. |

## 7. نقاط التحقق (Checkpoints)

| نقطة التحقق | التوقيت المقترح | ما تتم مراجعته |
| :--- | :--- | :--- |
| **CP-01** | عند كل تحميل للبيانات | اكتمال الحقول الأساسية وصحة المعرفات. |
| **CP-02** | يوميًا | تكرار أرقام الحجز وصحة تسلسل تواريخ الإقامة. |
| **CP-03** | يوميًا أو حسب دورة العمل | مطابقة قيمة الحجز وحالة الدفع مع المصدر المالي. |
| **CP-04** | أسبوعيًا | القيم خارج القواميس واتساق الفندق والمدينة والغرفة. |
| **CP-05** | شهريًا | اتجاهات مؤشرات الجودة والمشكلات المفتوحة والمتأخرة. |

## 8. مؤشرات الأداء والمتابعة (KPIs)

| المؤشر | طريقة القياس | المستهدف الأولي |
| :--- | :--- | :--- |
| **نسبة اكتمال رقم الحجز** | $\frac{\text{السجلات ذات رقم الحجز}}{\text{إجمالي السجلات}} \times 100$ | 100% |
| **معدل تكرار رقم الحجز** | $\frac{\text{المعرفات المكررة}}{\text{إجمالي المعرفات}} \times 100$ | 0% تكرار غير مبرر |
| **نسبة صلاحية التواريخ** | $\frac{\text{السجلات ذات تواريخ صحيحة وتسلسل صحيح}}{\text{الإجمالي}} \times 100$ | 100% |
| **نسبة الالتزام بالقيم المرجعية** | $\frac{\text{القيم المطابقة للقاموس}}{\text{القيم المفحوصة}} \times 100$ | 100% بعد اعتماد القواميس |

## 9. أصحاب المصلحة والأدوار المقترحة

| الدور | المسؤولية |
| :--- | :--- |
| **مالك بيانات الحجوزات** | اعتماد التعريفات والقواعد والعتبات وحسم الاستثناءات. |
| **مالك العملية التشغيلية** | تحديد متطلبات الحجز والإقامة وأثر العيوب. |
| **مالك بيانات الدفع** | تأكيد القيم المالية وحالات الدفع ومصدر المطابقة. |
| **مشرف البيانات** | متابعة القاموس والجودة اليومية وتنسيق معالجة المشكلات. |
| **محلل جودة البيانات** | تنفيذ الفحص والقواعد وتحليل النتائج وقياس المؤشرات. |
| **الفريق التقني** | تنفيذ ضوابط التحقق والتكامل والجدولة ولوحة المتابعة. |

## 10. المخرجات المتوقعة
* وثيقة نطاق المشروع وخطة التنفيذ.
* سياسة جودة البيانات المعتمدة.
* قائمة عناصر البيانات ذات الأولوية ومبرراتها.
* قاموس بيانات وتعريفات وقيم مرجعية معتمدة.
* مصفوفة أبعاد الجودة وقواعد القياس والعتبات.
* تقرير Data Profiling وخط الأساس.
* سجل مشكلات وبطاقات معالجة وتحقيق.
* إجراءات إدارة المشكلات ونقاط التحقق ومسارات التصعيد.
* بطاقات مؤشرات الأداء ولوحة متابعة واتجاهات التحسن.
